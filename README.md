# Blog Project

This project is intended to be a blog where I can share my programming studies and everything I learn along the way. I will also document how I built this blog throughout its development. The project was built with the help of AI, but not entirely.

## Overview

This repository contains the source code for a blog application where I publish articles about programming and software development.

## Getting Started

1. Clone the repository.
2. Install the required dependencies.
3. Configure the environment variables.
4. Run the development server.

## Features

    - Create, list, edit and delete posts
    - Comment at posts
    - Rate posts
